👋 About me
My background is in Electrical & Electronics Engineering, and it shows in how I build software:
I like clear contracts between layers, predictable systems and performance I can measure.
I reach for simple, maintainable tools first and add complexity only when it earns its place.

- 🔭 Currently building Jobbers, an AI-assisted job search and application platform
- 🧱 Comfortable owning a feature end to end: schema, API, UI, deploy
- 🤖 Integrating AI into real products, not just demos
- ✍️ Writing on Hashnode and Substack
- 💬 Ask me about Next.js, TypeScript, Prisma, database design or AI integration
- 📫 Best way to reach me: LinkedIn or email
